# AXIOM — כל כלי הוא חוק

משחק חשיבה לוגי: בסודוקו יש חוק אחד לכל הלוח, ובשחמט לכל כלי יש תנועה משלו.
ב-AXIOM **לכל כלי יש חוק משלו**, והמטרה היא סידור שבו כל כלי על הלוח מקיים את החוק שלו.

## הרצה

אין תלויות. פותחים את `index.html` בדפדפן, או מגישים את התיקייה:

```sh
python3 -m http.server 8080   # ואז http://localhost:8080
```

## הכלים

| כלי | שם | החוק |
|---|---|---|
| ● | הבודד | אף שכן צמוד אליו (ישר, לא אלכסון) אינו ● |
| ▲ | התאום | בדיוק שכן צמוד אחד שלו הוא ▲ |
| ■ | השבט | כל ה-■ על הלוח מחוברים לקבוצה אחת |
| ◆ | המראה | בתא הסימטרי לו דרך מרכז הלוח עומד גם ◆ |
| ⬡n | המונה | בדיוק n מ-8 השכנים שלו (כולל אלכסון) תפוסים |
| ◈ | המסתורי | חוק נסתר. מסיקים אותו מדוגמאות ✓/✗ |

רמה נפתרת כשכל הכלים שבמגש הונחו וכל הכלים שעל הלוח מקיימים את החוק שלהם.
לכל רמה פתרון יחיד.

## מבנה

```
index.html               הדף
src/engine.js            חוקים, בדיקת תקינות, פותר, חוקים נסתרים ודוגמאות
src/levels.js            עשר הרמות (נוצר אוטומטית, לא לערוך ידנית)
src/app.js, style.css    הממשק
scripts/generate-levels.js   מחולל הרמות
scripts/verify.js            בדיקה שלכל רמה פתרון יחיד
scripts/test-engine.js       הפותר מול אכיפה גסה על לוחות קטנים
```

```sh
npm run verify     # בדיקת הרמות והמנוע
npm run generate   # בניית כל הרמות מחדש (דקות)
node scripts/generate-levels.js 7 9   # בניית רמות מסוימות בלבד
```

## איך נבנית רמה

המחולל מוצא לוח מלא ותקין באופן אקראי, ואז מעביר כלים למגש אחד אחד כל עוד נשאר פתרון יחיד
(הפותר מוודא). ב-◈ מסתירים קודם כדי שהשחקן יצטרך להניח אותו. הדוגמאות של ◈ נבחרות כך
שאף חוק אחר מהספרייה (`HYP` ב-`engine.js`) לא מתאים לכולן.

## להוסיף כלי חדש

1. חוק ב-`analyze` וגיזום חלקי ב-`cellOK` (בתוך `search`) ב-`engine.js`.
2. ציור ב-`pieceSVG` ב-`app.js` וצבע ב-`style.css`.
3. הוספה ל-`PIECES` ולאחת הרמות ב-`generate-levels.js`, והרצת `npm run verify`.
